# Leyes Prioritarias - Leyes-RD-Bot

Este archivo contiene la lista inicial de leyes, códigos, decretos y normas que deben cargarse primero en el repositorio para alimentar el bot jurídico dominicano.

## Objetivo

Priorizar las fuentes legales esenciales para que el bot pueda responder consultas frecuentes en materia de consumidor, civil, penal, inmobiliario, constitucional, administrativo, bancario, tributario, laboral, familia y tránsito.

## Nota de control

Cada ley debe cargarse usando la plantilla:

prompts/legal_document_template.md

Cada documento debe contener:

- Fuente oficial
- Fecha de descarga
- Estado de vigencia
- Archivo original PDF
- Texto separado por artículos
- Notas de verificación
